# AGENTS.md — правила работы в этом репозитории

## Язык
- Общение по-русски, простым языком, связными предложениями.
- Без калек с английского. В частности: не «рука» для experimental arm — говорить «ветка»/«вариант».
- Новый термин вводить только вместе с определением; сначала объяснить, потом использовать.
- Не заваливать длинными текстами: отвечать по делу.

## Метод
- Единственный источник правды — распределение токенов модели. Всё остальное (шаблоны, наборы токенов, метки) — только рамка чтения этого распределения, и это надо явно оговаривать.

## Порядок работы
- Не проводить эксперименты и не менять код без явного разрешения.
- Перед началом объяснить: что проверяем, как, на каких данных, что считаем успехом/провалом.
- Затем — план (какие файлы, что меняем, чем проверяем) и дождаться «да».
- Не изобретать методы/параметры на ходу; неочевидное выносить как вопрос, а не решать молча.
- Минимальный диф; ревью git diff; запуск тестов перед сдачей.
